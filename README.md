CredentialVault
CredentialVault is a blockchain-based credential management smart contract built with solidity. It allows authorized issuers to issue, retrieve, and revoke student credentials while keeping the credential record on the Ethereum blockchain.

FEATURES
-Authorize credential issuers
-Issue student credentials
-Store credential information on chain
-Retrieve student information
-Retrieve credential program information
-Retrieve credential issuer information
-Check whether a credential exists
-Check whether a credential has been revoked 
-Revoke credntials 
-Retrieve complete credential information
-Count issued credentials 

TECHNOLOGIES USED 
-Solidity
-Remix IDE
-MetaMask
-Ethereum Sepolia Testnet
-Etherscan
